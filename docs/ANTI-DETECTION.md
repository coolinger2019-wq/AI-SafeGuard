# 蜜罐反检测自检（F794b②）

> 对照公开的蜜罐识别工具签名（honeydet / kippo_detect / honeyscan 类思路）逐面自检。
> 结论三档：**✓ 通过**（有针对性防御）、**△ 有已知暴露面**（有缓解、诚实记录）、
> **✗ 未通过**（需修）。日期：2026-10-03（F794 交付时）。

## 设计基线（先于逐面检查）

1. **真协议栈优先**：ssh 走 russh 真 KEX（不是 banner 回显）；mysql/redis 用真实客户端
   实连验收过（0.5.9 MySQL 8 CLI / redis-cli / paramiko）。
2. **指纹可配**：`[honeypot.fingerprint]` 全协议 banner/版本启动时固定（H320）。
3. **红线**：所有响应合成、水印可归因（canary）——"被识破"的代价被设计为可控：
   蜜罐识破最多损失一个诱饵面，真实主机不受影响。
