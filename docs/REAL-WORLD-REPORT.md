### ③ TTP（真实攻击者长什么样）

- **RDP 撞库战役**：多来源共享同一伪造 cookie `mstshash=103.79.78.165`（≥9 个出口 IP
  共用同一工具）——协同型扫描，战役指纹是比单源频次更强的证据
- **凭证喷洒**：root/admin 实名撞库（spray_hit=true + credential_observed + 快路径定罪，
  三通道齐备的教科书样本）；假 Shell 认证通过后的侦察（support 账号 242 次命中、42 条
  踩点命令）是第一手 TTP 材料
- **代理滥用**：redis 端口 CONNECT/GET httpbin.org（把服务当开放代理/SSRF 跳板）、
  python-socks CONNECT 外连、RDP 端口混发跨协议载荷
- **测绘背景声**：随机 mstshash cookie + TLS 指纹采集——无害但若不降级会被 AI 升格
- **MCP 面结论**：公网 386 会话 96% 是 405 GET 普扫——**真实 agent 工具滥用未在公网
  现身**（预期偏差，如实记）：MCP 蜜罐现阶段价值是早早期信号面，不是主战场
