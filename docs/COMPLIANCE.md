# ISO/IEC 27001:2022 对照矩阵

> **定位说明**：ISO 27001 认证对象是**组织**（ISMS 管理体系），不是软件产品——产品没有"持证"一说。
> 本文件回答两个实际问题：
> 1. AI-SafeGuard 的功能能为**客户的** ISMS 提供哪些控制项支撑；
> 2. **开发本产品的过程**要对齐 27001 还差什么、在哪个版本关闭。
> 本矩阵不构成认证结论或法律意见。控制项编号依据 ISO/IEC 27001:2022（Annex A 共 93 项）。

状态图例：✅ 已落地 · 🔜 排入 0.2 · 🗓 排入 0.3 · ⛔ 产品不适用（组织层面建设）

| A.8.2 / A.5.15 | 特权访问与访问控制：整个程序以管理员运行，渲染攻击者内容的 GUI 与内核态操作同权限 | 🔜 0.2 P0 | 服务化拆分：提权引擎注册为 Windows 服务，GUI 以普通权限运行、经本地 API 连接 |

## 三、产品不适用、需组织自行建设的部分

- **人员控制全部（A.6.x）**：-screening、意识培训、纪律流程
- **物理控制全部（A.7.x）**：机房、工位、介质
- **组织控制大部分（A.5.x）**：ISMS 范围与方针、风险评估方法（标准 6.1.2/6.1.3）、SoA、内审（9.2）、管理评审（9.3）、持续改进（10.x）、供应商关系管理（A.5.19-5.22）
- **技术主题的运营部分**：容量管理（A.8.6）、恶意软件防护基线（A.8.7，产品本身是工具不是基线）、数据脱敏（A.8.11）、DLP（A.8.12）、时效同步（A.8.17）等
