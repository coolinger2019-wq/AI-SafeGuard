# 威胁模型（一页纸）

> 版本：2026-09（0.4.0）。原则：**克制与诚实**——写清边界比夸大能力重要。

## 产品定位

AI-SafeGuard 是**单机/小集群的主机入侵检测与处置工具**：蜜罐诱捕 → 事件流水线 →
快路径频次检测 / AI 慢路径分析 → 防火墙处置（Windows COM/WFP、Linux nftables+XDP），
带本地 GUI 与 REST API、组织协同（mTLS）、事件哈希链与远程转发。

## 防什么（在能力范围内）

| 威胁 | 防线 |
|------|------|
| 扫描 / 踩点（端口扫描、SYN flood、暴破探测） | 蜜罐诱捕 + 频次引擎/采样检测器，快路径自动封禁（TTL + 内网保护 + 审计） |
| 已知恶意基础设施（C2 等） | 威胁情报（Feodo）高置信度自动封禁，fed 情报仅标注 |
| Web 扫描器/攻击工具踩蜜罐 | 蜜罐记录 + L7 标签 + AI 上下文评估 |
| 日志被攻击者篡改掩盖行踪 | 事件哈希链（SHA-256 链式）+ 离线校验 + syslog 外发副本 |
| AI 建议被诱导"封全网" | 严格 schema（字段非法整条作废）、内网/回环永不自动封、灰度 TTL + 人工转正 |
| 协同情报投毒 | 跨节点只共享**建议**不共享命令；接收端本地复验；节点指纹绑定 + 吊销；quorum（可选） |
| 事件转发通道被利用 | 外发只读事件总线、失败只丢弃（无自反馈风暴）、不携带可执行语义 |

## 不防什么（明确非目标）

- **不对抗国家级 APT**：无内存防护、无 EDR 级进程行为链、无固件/内核完整性校验。
- **不是 NGFW/IPS**：无全量 DPI、无签名库（Suricata 子集为 0.5 计划）、不做线速过滤。
- **不替代系统加固**：补丁、最小权限、备份、MFA 仍然必需——本产品是纵深防御的一层。
- **AI 不是决策者**：AI 建议默认人工确认；自动应用是可选的、带严重度阈值与灰度 TTL。

## 信任边界

```
┌─ 本机可信域 ──────────────────────────────────────────────┐
│ 引擎（root/LocalSystem）：防火墙、蜜罐、捕获、事件库        │
│ GUI（普通用户）：仅经本地 API（127.0.0.1 + Bearer）读数据   │
└──────────────┬───────────────────────────┬────────────────┘
        事件外发（UDP/TCP，只读副本）    组织协同面（mTLS 双向证书）
               ▼                            ▼
        syslog/SIEM（不可信传输信道，      协调者与其他节点
        完整性以本地哈希链为准）           （各自独立运行，失联不伤本机）
```

- **本地 API**：仅回环 + Bearer token；GUI 远程模式经它读写，无远程代码执行面。
- **组织协同面**：独立 mTLS 监听（建议绑内网），客户端证书须链到组织 CA；
  node↔指纹绑定 + 吊销；跨节点消息带时钟窗校验。
- **AI 上下文**：蜜罐载荷/事件摘要一律按不可信输入包裹（声明非指令 + 清洗 + 截断）。
- **捕获隐私**：control 模式只采集 TCP 纯 SYN 元数据；full 模式载荷仅在被判定可疑时
  截断留存（≤120 字符、控制字符清洗），AF_PACKET 不开混杂模式，流表不落盘。

## 关键失效模式（失效时会发生什么）

| 组件失效 | 结果 |
|----------|------|
| AI / 外网 LLM 不可达 | 慢路径失效，快路径与蜜罐照常；AI Key 缺失留痕 |
| 捕获不可用（缺驱动/无 CAP） | 采样检测降级，蜜罐快路径照常 |
| XDP 附加失败 | nftables 兜底，语义不缩水 |
| 协调者失联 | 各节点独立运行，本机处置不受影响 |
| syslog/webhook 目标宕机 | 外发丢弃该条并限频留痕，引擎不受影响 |
| 事件库被删 | 防火墙规则启动 resync 按库重灌——库没了规则账本也没了（nft 集合仍活到重启） |
